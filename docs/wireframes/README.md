# Wireframes

Lo-fi wireframe sources exported from the design canvas. They use the canvas's component markup (`<x-dc>`), so open them as text for reference; they won't render on their own.

To see them rendered, with the full v1 to v6 design history, open https://claude.ai/artifact/GJwMAiLJF1WNrqsd6QT6ae (v6 is the current direction).

| File | Screen |
|---|---|
| `V6Story.dc.html` | Story view: notebook centre, "For this item" panel on the right |
| `V6Epic.dc.html` | Epic view: PRFAQ centre, Alignment panel on the right |
| `V6Session.dc.html` | The same screen in session mode |
| `V6Checks.dc.html` | Both checks, opened from the meters |
| `V5Ingest.dc.html` | Adding a source (modal in v6) |
| `V5Shape.dc.html` | Shaped view: notes and output side by side |
| `V5Lenses.dc.html` | Team settings for the AI teammate |
| `V5Ready.dc.html` | Jira sync, the sprint rule and drift |

All names, numbers and file paths in the wireframes are illustrative, and match `seed/`.
